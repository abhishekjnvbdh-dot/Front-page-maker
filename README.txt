FRONT PAGE MAKER — FREE INSTALLABLE WEB APP

CONTENTS
- index.html: app interface
- styles.css: Liquid Glass styling
- app.js: editor, templates, saving and export
- manifest.webmanifest: installable PWA settings
- sw.js: offline caching
- icon.svg: app icon

HOW TO USE ON ANDROID
1. Upload these files to a free static HTTPS host (for example, GitHub Pages).
2. Open the published HTTPS website in Chrome on Android.
3. Open Chrome menu (three dots) > Install app or Add to Home screen.
4. Confirm. Front Page Maker will appear on your Home Screen.

IMPORTANT
- A Progressive Web App (PWA) is not an APK. It installs through Chrome.
- Service workers and PWA installation require HTTPS (or localhost).
- Designs are stored locally in the browser on this device. Clearing browser site data may remove them.
- PDF: tap Print / PDF, then choose Save as PDF in the Android print dialog.
- PNG export uses browser SVG/canvas support; if a browser blocks it, use Print / PDF.
- Google Fonts are used when online; system fonts are used as fallback.
- This project does not send your data to a server.
